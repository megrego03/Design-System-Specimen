Design System Specimen

A reusable visual foundation for Deliverable: Design-System Specimen

S1 - Foundation and Reset

This project uses a selective reset that removes only browser defaults that interfere with predictable layout while preserving useful native behaviors and interactions.

Box Sizing

Border-box sizing is applied globally so padding and borders are included within an element's declared dimensions.

Body Margin

The browser's default body margin is removed so page spacing is controlled consistently through design-system spacing tokens.

Responsive Media

Images use a maximum width of 100% to prevent them from overflowing their containers.

Form Typography

Form controls inherit the surrounding font so controls remain visually consistent with the typography system.

Intentionally Preserved Defaults

Native focus indicators and semantic control behavior are not globally removed. Custom focus styling is added later without eliminating keyboard visibility.

Font Source and Fallback

The body stack uses Arial, Helvetica, and a generic sans-serif fallback. The display stack uses Georgia, Times New Roman, and a generic serif fallback.

Source: System-provided fonts. Arial and Georgia are used when available, with additional system and generic fallback families provided.

Fallback Behavior If the preferred typeface is unavailable, the browser proceeds through the declared font stack until a supported typeface is found.

Spacing and Elevation

Compact spacing is used within related controls, standard spacing separates component content, and larger spacing separates major sections. Elevation is required for surfaces requiring stronger visual emphasis.
